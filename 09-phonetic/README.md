# 音标查询

单词贴进去，英式美式音标、音节、重音位置、词性释义一次给全。纯本地算，不联网、不登录。

系列第九个工具，一天一个。

## 功能

- **一次查多个**：一行一个（也认逗号、顿号、分号），免费查 3 个，解锁后 12 个；重复的自动去掉并按小写比对
- **英式 / 美式 / 英美并排**：`schedule` 这种两套差得远的，一行里同时给 `ˈʃedjuːl` 和 `ˈskedʒuːl`，不用来回切
- **音节拆开**：`ˈʃed · juːl`、`ɪn · ˈvaɪ · rən · mənt`，长词一眼看出在哪断
- **重音位置**：直接说「重音在第 2 个音节」，不让用户自己数
- **变形词回原形**：`apples → apple`、`running → run`、`went → go`，并标出是复数 / 过去式 / 现在分词
- **词库外不装作认识**：音标按拼读规则推算，卡片上明确标「推算」，并给 2–3 个拼写建议
- **记录本**：查过自动记，免费 5 条，解锁 60 条，同一个词只留最新一条，可整份复制
- **内置词库 600+ 条**：生活常用 + 学术 + 商务，每条都带词性和中文释义

## 核心设计

### 音节从音标算，不写在数据里

词库里只存 `word | 英式 | 美式 | 词性释义`，音节数和重音位置都是现场算的。
反过来把 `音节=2` 写进数据，改一个音标就会出现「音标 3 个音节、字段说 2 个」的错位。

算法三步：

1. **切 token**：先把双元音（`eɪ aɪ ɔɪ aʊ əʊ oʊ ɪə eə ʊə`）和长元音（`iː uː ɑː ɔː ɜː`）整体认成一个音节核，否则 `eɪ` 会被数成两个音节
2. **分音节**：两个音节核之间若有 k 个辅音，`k ≥ 2` 时把最后一个留给后一个音节做声母（`hɪst|ri`），`k ≤ 1` 时全给后面（`kəˈnekt`）
3. **词尾成节辅音**：`apple / sudden / nation` 这类，音标末尾是「辅音 + l/n/m」，要单独补一个音节，切点在最后一个音节核之后

第 3 步的切点是 `ap|ple` 而不是 `a|pl`——切在核后面才念得出来，切在最后一个辅音前面会得到半个声母。

测试对整本词库逐条检查「音节 ≥1」「重音位置落在 1..音节数 之间」，任何一条不成立就说明音标本身写坏了。

### 重音：取主重音，不看次重音

音标里 `ˌ` 是次重音、`ˈ` 是主重音。`ˌɪntəˈnæʃnəl` 有两个标记，
必须只认 `ˈ`，否则 `international` 会被报成第 1 个音节重读。
回读方式是数 `ˈ` 之前有几个音节核，再 +1。

### 词形还原：先查表，再走规则

`went / children / better` 这类规则算不出来的，走 `IRREGULAR` 表；
规则能算的走后缀：`-ies → y`、`-ed`、`-ing`（补回哑 e：`making → make`）、双写辅音（`running → runn`，再去掉一个）。
规则按「候选词长度 ≥2 且在词库里」筛，第一个命中的就是原形；都不中才当生词处理。

### 词库外：拼读规则 + 明确标注

G2P 表按「最长匹配优先」扫：`tion → ʃn`、`igh → aɪ`、`ch → tʃ`、`a_e → eɪ`（辅音 + e 结尾读长音）。
推算出来的音标一定带 `source: 'rule'`，卡片显示「推算」标签、释义写「词库暂未收录」，
再给几个编辑距离相近的词做建议。**不假装认识，是这类工具最要紧的一条。**

### 失败返回对象，不抛异常

`{ ok:false, code, message }`，页面把 `message` 直接弹提示。code 给测试和分支用：
`EMPTY` / `TOO_LONG` / `TOO_MANY` / `NOT_WORD`。
`TOO_MANY` 是特例：仍然把前 N 个查出来，只附一句提示——用户贴了 6 个词，给 3 个结果比给 0 个好。

## 广告位

`core/ads.js` 顶部有一个常量：

```js
var AD_UNIT_ID = '';   // 拿到流量主后填这里
```

**现在是空的，这是有意的**。新小程序没有流量主权限（需累计独立访客 ≥1000），此时填任何 ID
都会触发「广告拉取失败」。所以代码做了降级：拉不到广告 → 视为解锁成功，直接放行。

## 已知限制

- 词库 600+ 条，覆盖常用词为主，专业词要扩充 `core/phonetic.js` 顶部的 `RAW` 表
- 推算音标只保证「念得出来」，和词典音标会有出入，所以一律标成「推算」
- 音标是文本渲染，不提供发音音频（播放要联网取音频，与「纯本地」冲突）
- 记录存本地 Storage，换设备不同步
- 音节切分用「最大声母」启发式，个别词（如 `sudden`）会切成 `ˈsʌ · dn`，与词典的 `sʌd · n` 略有差别
