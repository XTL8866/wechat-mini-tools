# 取色

传一张图上去，点哪儿取哪儿，HEX / RGB / HSL 三种写法一起给。纯本地读像素，不联网、不登录。

系列第六个工具，一天一个。

## 功能

- **点图取色**：按原图坐标取像素，越界自动夹到边缘，点歪了不会崩
- **三种写法同屏**：HEX、RGB、HSL 一起给，不用自己换算，也不会「换个格式就发现色偏了」
- **色名 + 调子**：告诉你这个颜色最接近哪个常用色名（91 个传统色），以及它是深是浅、偏冷偏暖
- **对比度**：白字 / 黑字在这个底色上的对比度，直接给数字，配色不再凭感觉
- **扫主色**：按面积排，相近的自动并掉，不会给你三档一样的蓝；免费 3 个，解锁后 6 个
- **色卡**：取过的颜色自动进色卡、自动判重，点一下取回，长按删掉；免费 6 张，解锁后 60 张
- 全本地：图只在内存里读一遍像素，不上传，不保存原图

## 核心设计

### 一切颜色都收敛成三个数

`core/color.js` 里 `norm()` 是唯一的入口：字符串、`{r,g,b}`、色卡项都收敛成 `{r,g,b}`，
出去的时候再按需要拼成 `#RRGGBB` / `rgb()` / `hsl()`。这样页面不用关心上游给的是什么形状。

对外一律输出大写 `#RRGGBB`，内部判重一律用小写 `#rrggbb` 做 key ——
不这么做的话 `#FFF` 和 `#ffffff` 会被当成两个色，色卡里就会出现两张一模一样的。

### 失败返回对象，不抛异常

`{ ok:false, code, message }`。页面把 `message` 直接弹 toast，不用在每处 try/catch，
也不会因为一个手滑输入把整页打白。code 是给测试和分支用的（`EMPTY` / `TOO_LONG` /
`BAD_HEX` / `BAD_LENGTH` / `NO_IMAGE` / `DUP` / `FULL`）。

### 主色是按面积加权 + 距离合并

先按 16 级量化桶计数（每通道 `>> 4`），按像素数排序，再逐个检查：
和已选中的颜色距离小于 26 就跳过。没有这一步，一张渐变天空会给出三个几乎一样的蓝。

面积用的是抽样估计：大图最多抽 4 万个点（`SAMPLE_CAP`），比例照样准，但不会卡。

### 取点是夹取，不是报错

`pick(pixels, w, h, px, py)` 把坐标夹在 `[0, w-1]`，点在图片边缘外面也返回最近的那个像素。
用户手指点偏是常态，这时候报错没有任何意义。

## 广告位

`core/ads.js` 顶部有一个常量：

```js
var AD_UNIT_ID = '';   // 拿到流量主后填这里
```

**现在是空的，这是有意的**。新小程序没有流量主权限（需累计独立访客 ≥1000），此时填任何 ID
都会触发「广告拉取失败」。所以代码做了降级：拉不到广告 → 视为解锁成功，直接放行。

## 已知限制

- 色名表是 91 个常用传统色，判定用的是红均值加权距离；冷门色名（比如「蟹壳青」那种偏门的）
  命中的距离会偏大，但不会给错名字
- 只取单个像素，不做邻域平均，所以图上有噪点时取到的值会跳 —— 想要平均值可以后续加 3×3 取样
- 不支持透明度：`#RGBA` / `rgba()` 里的 alpha 会被丢掉，只算 RGB
- 色卡存在本地 Storage，换设备不同步
- 原图不保存，只存缩到 1080 的像素副本在内存里，退出即释放
