# 起名

填上姓、选个类型、敲两个关键词，直接出带寓意的名字。纯本地运行，不联网、不登录。

系列第五个工具，一天一个。

## 功能

- **四种类型**：男孩 / 女孩 / 中性 / 品牌。品牌不填姓，走「短、好记、不生僻」那一路
- **关键词对上字义**：每个字带语义标签，输入「山」能捞到山系的字，「山水」连写会拆成两组分别匹配
- **音韵会挑刺**：三声连读扣分（两个上声挨着念着拗口）、同声母粘牙扣分、名字和姓同音重罚
- **寓意是字义的拼接**：每个名字下面写清两个字各是什么意思，不是一句空泛的「寓意美好」
- **拼音、声调型、笔画**：`lín yán dù / 平仄 / 20 画`，取名字的时候这些都要看
- **去重**：同一批不重名，换一批不会拿到刚看过的；首字尽量不重复，二十条看着像二十个思路
- 免费 3 个，激励视频解锁后一次 20 个

## 核心设计：字不是随手拼的

`core/names.js` 里每个字是一条：

```js
{ c: '屿', py: 'yǔ', t: 3, s: 6, g: 'n',
  tags: ['山', '海', '岛'], m: '海中小岛，安静自持' }
```

`t` 声调、`s` 笔画、`g` 性别倾向、`tags` 语义标签、`m` 一句字义。

生成分三步：

1. **筛池**：按类型过滤（男孩名不用纯女性字），品牌池再砍掉偏柔美的字——「沛晗」做招牌不像话
2. **打分**：关键词命中 +45/字；三声连读 −20；同声母 −12；与姓同音 −35；名字用姓那个字 −60；笔画差 3–10 加分、完全相同扣分；两字语义重叠扣 6（「泽澈」都是水，读着像同义反复）
3. **挑**：命中关键词的组合先占满，不够才轮到通用池。分四轮，越往后越宽松：两字全新 → 单字最多用两次 → 只求首字不同 → 全放

**为什么命中池要先占满**：字库一百来个字，「两字全新」的组合源源不断。一把抓的话，低分的通用候选会靠「用字不重复」挤到前面，关键词就白填了。第一版就是这么错的，要 6 条时后面 3 条跟关键词毫无关系。

**为什么分四轮**：不限制的话，20 条会变成「陈X安」连着十来个。四轮是逐级放宽用字频率，不是逐级放宽命中的要求。

**为什么两个字只有一种组合**：`峻舟` 和 `舟峻` 是同一组字。生成时按字典序做 key 去重，保留分数更高的那个方向（顺序不同，读音也不同）。

## 音韵规则是算出来的，不是摆样子

- **三声连读**：两个上声挨着要变调（ˇˇ → ˊˇ），念着别扭，直接 −20
- **同声母**：`zh/ch/sh` 单独处理，`张知` 这种粘牙的 −12
- **与姓同音**：姓陈（chén）时「晨」−35，不然「陈晨」念出来听不出边界。这条在测试里是精确对数的，不是抽样的
- **用姓那个字**：−60，直接从候选里压到看不见

## 广告位

`core/ads.js` 顶部有一个常量：

```js
var AD_UNIT_ID = '';   // 拿到流量主后填这里
```

**现在是空的，这是有意的**。新小程序没有流量主权限（需累计独立访客 ≥1000），此时填任何 ID 都会触发「广告拉取失败」。所以代码做了降级：拉不到广告 → 视为解锁成功，直接放行。

## 已知限制

- 字库是本地固定的 101 个字，不会「学习」你喜欢的风格。想加字改 `CHARS` 数组就行，其余逻辑自动生效
- 生僻字没收录（`彧`、`珩` 收了，`頔`、`翀` 没收）
- 姓的拼音只覆盖常见姓 + 12 个复姓，查不到就只注名的音，不硬编
- 不含五行八字、笔画吉凶这类说法——那不是能算出来的东西，本文具只做字义和音韵
- 没有收藏功能，关掉就没了；复制走剪贴板，不落盘
