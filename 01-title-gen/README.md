# 标题生成器

输入一个产品名，生成可直接使用的抖音 / 小红书标题。纯本地运行，不联网、不登录、不上传输入内容。

第一个小程序。系列共 10 个工具，一天一个。

## 功能

- **两个平台**：抖音（口语、短、有冲突）／小红书（笔记感、可收藏），话术分开
- **三种风格**：爆款（强钩子）、走心（情绪）、带货（卖点前置）
- **免费 3 条**，激励视频解锁后一次 15 条
- 每条显示风格标签与字数，超过 30 字标「偏长」但不截断
- 点「复制」直接进剪贴板
- 支持「换一批」：连续生成不会重复，模板池用尽才回到起点

## 跑起来

**小程序**

1. 打开微信开发者工具 → 导入项目 → 选 `01-title-gen` 目录
2. AppID 选「测试号」即可（`project.config.json` 里是 `touristappid`）
3. 编译，直接可用

**逻辑自测**

```bash
node test.js     # 20 项断言，覆盖去重、跨风格补齐、边界输入
```

**浏览器预览**

直接用浏览器打开 `preview/index.html`。它引用同一份 `core/titles.js`，只换渲染层，所以界面和真机一致。

## 广告位

`core/ads.js` 顶部有一个常量：

```js
var AD_UNIT_ID = '';   // 拿到流量主后填这里
```

**现在是空的，这是有意的**。新小程序没有流量主权限（需累计独立访客 ≥1000），此时填任何 ID 都会触发「广告拉取失败」。所以代码做了降级：拉不到广告 → 视为解锁成功，直接放行，不让用户卡在一个点了没反应的按钮上。

拿到流量主后，把真实 `adUnitId` 填进这个常量，其余代码不用动。banner 广告同理，`pages/index/index.js` 里的 `adUnitId` 为空时 `<ad>` 组件不渲染。

## 页面结构

单一页面 `pages/index`：

| 区块 | 说明 |
|---|---|
| 输入 | 30 字上限，改主题会清空旧结果（避免标题和输入对不上） |
| 平台 | 分段控件，切换后清空结果 |
| 风格 | chip 选择，切换后清空结果 |
| 主按钮 | 无结果时「生成 3 条标题」，有结果时「换一批」 |
| 结果列表 | 序号 / 标题 / 风格 / 字数 / 复制 |
| 解锁 | 免费 3 条之外的部分 |
| banner | 未配 ID 时不渲染 |

## 已知限制

- 词库是模板组合，不是 AI 生成。模板池抖音 28 条、小红书 24 条，用尽后会重复并给出提示
- 风格池容量不均：走心风格抖音只有 8 条，要凑 15 条时会跨风格补齐（会有提示）
- 没有历史记录，不存草稿
- 未做云同步，换设备数据不互通（本来也不需要）

## 设计取舍

**为什么不用 AI 接口**：需求是「本地运行、不用登录」。接大模型要密钥、要后端、要计费，还得处理超时和审核。模板组合在「够用」和「零成本」之间更划算，而且响应是即时的。

**为什么超长不截断**：截断会让句子失去语义（「别人都在夸这个，我来说句实话」砍到 30 字就成了半句话）。宁可标「偏长」让用户自己决定。
