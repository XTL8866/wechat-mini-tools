# 金额大写

输入金额，输出人民币大写（票据写法），并给出亿 / 万 / 元三级拆分和写法要点。纯本地计算，不联网、不登录。

系列第十二个工具，一天一个。

## 功能

- **一遍算出大写**：`1234.56` → `壹仟贰佰叁拾肆元伍角陆分`，小写留在旁边核对
- **零的处理按票据规范**：中间连着几个零只写一个（`100500` → `壹拾万零伍佰元整`）；上亿时万级整级为空也只留一个零（`100000001` → `壹亿零壹元整`）
- **「整」字的规则**：到元为止写「整」，到角为止写「整」，有「分」就不写
- **角为零、分不为零，元后补零**：`107.06` → `壹佰零柒元零陆分`，不是「壹佰零柒元陆分」
- **「壹拾」不省字**：`10` 写 `壹拾元整`，不写「拾元」——票据上「拾」前面可以加字改成「贰拾」
- **三级拆分**：亿级 / 万级 / 元级各是多少、读成什么，一眼看清那个零是从哪来的
- **写法要点自证**：三条规则后面的例子是引擎当场算的，不是手写的
- **批量转换**：一次多笔（免费 1 笔，解锁后 8 笔），去重、逐笔给大写
- **一条复制**：`¥1,234.56 = 壹仟贰佰叁拾肆元伍角陆分`，直接贴进单据

## 核心设计

### 用「分」为单位的整数算

`1234.56 * 100` 在浮点里是 `123455.99999999999`，`Math.floor` 一下就是 `123455`，
一分钱没了，大写直接写错。所以入口就把金额折算成整数分，之后全程整数：

```
yuan = floor(cents / 100)     整数部分
jiao = floor(cents % 100 / 10)
fen  = cents % 10
```

上限定在 `99999999999999` 分（9999 亿元 - 1 分）：再大也要 4 位一级地加「万亿」，
票据上基本用不到，不如卡死报错。

### 零的规则：一个待补标记，等非零数字来兑现

写错的绝大多数都在零上。这里的做法是**遇到 0 只记一个标记，等下一个非零数字出现时才把「零」吐出来**：

```
遍历每一位（从高位到低位）
  该位是 0  → pendingZero = true
  该位非 0  → 若 pendingZero 且不是开头，输出一个「零」；再输出 数字+位名
  走到一组的末位（个位）→ 这一组有非零数字才挂级名（万 / 亿）
```

这个结构一次解决三件事：

| 情况 | 输入 | 输出 | 为什么自动对 |
|---|---|---|---|
| 组内连续零 | `100500` | 壹拾万零伍佰 | 三个 0 只置一次标记，只吐一个零 |
| 组尾的零 | `110` | 壹佰壹拾 | 后面没有非零数字来兑现，标记不吐 |
| 跨级的零 | `100000001` | 壹亿零壹 | 万级整级为空，标记跨过整级，到个级才吐出 |

靠人肉枚举永远测不完，所以 `test.js` 第 6 组换了个思路——**跑不变量**：
0–9999 全量，检查「不出现连续两个零」「结尾不是零」「大写里的数字顺序必须等于小写去掉 0 之后的顺序」。
第三条最狠：规则写歪了，顺序一定乱，891 个数字里随便漏一个都会被抓住。

### 「壹拾」不写成「拾」

口语里 10 就是「十」，票据上必须「壹拾」。因为单写「拾」，前面填一个字就能改成「贰拾」「叁拾」，
金额翻倍。所以 10–19 一律输出「壹拾X」，不做口语化省字。

### 逗号是双关的

批量输入里逗号既可能是分隔符，也可能是 `1,234.56` 的千分位。
先按换行 / 分号 / 顿号切，再看每一段像不像带了千分位的单个金额：

```
/^\d{1,3}(,\d{3})+(\.\d+)?$/  → 像，整段留作一笔
否则                          → 不像，把逗号当分隔符切开
```

不然 `1,234.56` 会被切成一元和二三四点五六，金额直接错两个数量级。

### 输入规则

- 接受 `1234.56` / `1,234.56` / `￥1,234.56` / `1234` / `.5` / `12.5元`，千分位、货币符号、结尾「元」都当装饰
- 小数超过两位：四舍五入到分，并给提示（不静默改数）
- 负数直接拒：票据上没有负数，能填进去说明是填错了
- 超过 9999 亿元报 `BIG`，输入超 40 字符报 `LONG`

失败一律返回 `{ ok:false, code, message }`，不抛异常。`code`：`EMPTY` / `BAD` / `NEG` / `LONG` / `BIG`。

## 广告位

`core/ads.js` 顶部有一个常量：

```js
var AD_UNIT_ID = '';   // 拿到流量主后填这里
```

**现在是空的，这是有意的**。新小程序没有流量主权限（需累计独立访客 ≥1000），此时填任何 ID
都会触发「广告拉取失败」。所以代码做了降级：拉不到广告 → 视为解锁成功，直接放行。

## 已知限制

- 只做人民币正数金额，不做外币、不做「负」前缀（对账缺口请自己先算出差额）
- 只输出「壹拾」式票据写法，不做「十元整」这种口语写法
- 上限 9999 亿元，不做「万亿」级
- 不判断金额本身合不合理（比如合同金额是否超预算），只负责把数字读对
- 结果不存历史，刷新即清空
