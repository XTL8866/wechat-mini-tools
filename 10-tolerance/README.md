# 公差查询

输基本尺寸、选孔和轴的公差带，上偏差、下偏差、极限尺寸、配合类型一次算出来。纯本地查表计算，不联网、不登录。

系列第十个工具，一天一个。

## 功能

- **一个尺寸一组配合**：输 `25`，孔选 `H7`、轴选 `g6`，三张卡分别给孔、轴、配合
- **偏差和极限尺寸一起给**：`+21 / 0 μm`、`25.000–25.021`，不用自己加一遍
- **自动判配合类型**：最小间隙 ≥0 是间隙配合，最大间隙 ≤0 是过盈配合，跨零线是过渡配合，最大最小都算出来
- **换配合即时重算**：点一下轴公差带（`g6 → k6 → s6`），间隙、过渡、过盈跟着变，不用重新输入尺寸
- **批量对照**：同一个配合套到一批尺寸上（免费 1 个，解锁后 8 个），出逐尺寸对照表
- **一条复制**：五行文本，孔/轴的偏差和极限尺寸、配合结论、配合公差，直接贴进图纸说明
- **孔公差带 6 个、轴公差带 7 个**：H7/H8/H9/H11/K7/N7，g6/h6/h7/k6/n6/p6/s6，覆盖绝大多数常规配合
- **支持 0–500mm、IT1–IT18**：底层按 GB/T 1800.1 全表实现，界面只挑常用的露出来

## 核心设计

### 只存三张表，孔的偏差算出来

`core/tol.js` 里只有三组原始数据：

1. 标准公差 `IT1–IT18`，13 个尺寸段（`IT`）
2. 轴的上偏差 `es`，`c d e f g h` 六个代号，25 个细段（`ES_AH`）
3. 轴的下偏差 `ei`，`k m n p r s` 六个代号，25 个细段（`EI_KS` + `EI_K`）

孔的偏差**不另抄一张表**，按国标的换算规则从同名轴推出来：

| 代号 | 规则 |
|---|---|
| A–H | `EI = -es` |
| JS | `ES = +IT/2`，`EI = -IT/2` |
| K–N | 等级 ≤IT8：`ES = -ei + Δ`；>IT8：`ES = -ei` |
| P–S | 等级 ≤IT7：`ES = -ei + Δ`；>IT7：`ES = -ei` |

其中 `Δ = IT(n) - IT(n-1)`。抄两张表的话，改错一位不会有任何东西报错；
算出来的话，`es - ei = IT` 这条恒等式就成了自检——`test.js` 第 6 组对 6 个孔代号 × 5 个等级 × 6 个尺寸段、
7 个轴代号全跑一遍，`Δ` 一旦漏加立刻挂。

验算：`⌀25 K7` → 轴 `k` 的 `ei = +2`，`IT7 - IT6 = 21 - 13 = 8`，`ES = -2 + 8 = +6`，`EI = 6 - 21 = -15`，
和手册上的 `+6 / -15` 对得上。

### 两套尺寸分段，不能混

IT 表用 13 个粗段（`≤3 / 3–6 / … / 400–500`），但基本偏差在 `50–80`、`80–120`、`120–180` 这些大段里还会再分：
`r` 在 `50–65` 是 `+41`、在 `65–80` 是 `+43`，`s` 分别是 `+53` 和 `+59`。
所以 `BANDS` 用 25 个细段查偏差，`COARSE` 把细段映射回粗段查 IT。
两者共用一条索引，就不可能取到不同段的数。

界面上「尺寸段」显示的是**粗段**（`⌀25 → 18–30`），因为图纸上说的是 IT 等级所在的段，
不是内部查偏差用的细段——显示 `24–30` 会让人以为分档和手册不一样。

### 间隙取正、过盈取负，先算两端再判类型

不去分三种情况各写一套公式，而是一律算：

```
xmax = ES(孔) - ei(轴)
xmin = EI(孔) - es(轴)
```

- `xmin ≥ 0` → 间隙配合，间隙 `xmin ~ xmax`
- `xmax ≤ 0` → 过盈配合，过盈 `-xmax ~ -xmin`
- 跨零 → 过渡配合，最大间隙 `xmax`、最大过盈 `-xmin`

配合公差恒等于 `IT(孔) + IT(轴)`，也恒等于 `xmax - xmin`。这两条在测试里各查一次。

### 极限尺寸补满三位小数

`25–25.021` 会被读成上下限都是整数，在图纸上是要出事的。`fmtRange` 一律 `toFixed(3)`，
所以是 `25.000–25.021`。测试专门盯了这一条。

### 失败返回对象，不抛异常

`{ ok:false, code, message }`，页面把 `message` 直接弹提示。
code 给测试和分支用：`EMPTY` / `BAD` / `LONG`。
批量里只要有一条非法就整体失败，**不静默丢掉**——悄悄少算一个尺寸比报错危险得多。

## 广告位

`core/ads.js` 顶部有一个常量：

```js
var AD_UNIT_ID = '';   // 拿到流量主后填这里
```

**现在是空的，这是有意的**。新小程序没有流量主权限（需累计独立访客 ≥1000），此时填任何 ID
都会触发「广告拉取失败」。所以代码做了降级：拉不到广告 → 视为解锁成功，直接放行。

## 已知限制

- 只实现 `c d e f g h js k m n p r s` 这些轴代号；`a b` 和 `t u v x y z` 没做（用得少，数据量大）
- 基本尺寸上限 500mm。500–3150mm 国标另有一套表，没抄
- IT01 / IT0 没做，最小到 IT1
- 不查「配合优先选用表」，常用配合靠自己选；给的是数值是否合适，不是「该不该用这个配合」
- 计算用的是标准公差数值表，和旧版国标（GB/T 1800-79）的分档略有差别，老图纸要留意
- 结果不存历史，刷新即清空
