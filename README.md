# 一天一个小工具

10 个纯前端单页工具，一天做一个。每个都能直接导入微信开发者工具跑起来，不带后端、不需要登录、不联网。

做这个系列的原因：很多小需求不值得开发一个 App，但确实天天烦人。抠一个颜色、查一个公差、拼一条参考文献、想一个标题——这些事每次只花几分钟，一年下来是几十个小时。

## 共同约定

- **纯前端**：没有后端，没有接口，所有计算在本地完成
- **不登录**：不需要账号，不采集任何用户信息
- **单一页面**：一个页面解决问题，不做多层跳转
- **同一套视觉**：白底 + 单一主色，字号和间距统一，看一个就认识全部
- **广告降级**：激励视频在拿不到广告位时直接放行，不拦用户

## 关于广告

代码里预留了激励视频的位置，但默认 `AD_UNIT_ID` 是空的，此时广告逻辑降级为「直接解锁」。

原因：新小程序没有流量主权限（需累计独立访客 ≥1000），填任何 ID 都会拉取失败，用户点解锁会毫无反应。所以默认放行是唯一合理的做法。拿到流量主后填上真实 ID 即可，不需要改其他代码。

详见各项目的 README。

## 用法

每个子目录都能独立导入微信开发者工具：

```
导入项目 → 选择子目录 → AppID 选「测试号」→ 编译
```

## 目录

```
mini-apps/
├── _shared/           公共视觉规范
└── 01-title-gen/
    ├── miniprogram/   小程序源码
    ├── preview/       浏览器预览版（录屏用）
    ├── video/         介绍片生产链
    └── README.md
```

每个项目都附一条介绍片的完整生产链（截图 → 逐帧合成 → 配音），源码在 `video/` 下，可以重跑。
