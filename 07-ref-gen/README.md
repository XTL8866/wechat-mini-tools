# 参考文献

选类型、填格子，直接出 GB/T 7714-2015 格式的著录条目。纯本地拼装，不联网、不登录。

系列第七个工具，一天一个。

## 功能

- **八种文献类型**：期刊 [J]、专著 [M]、学位论文 [D]、会议 [C]、专利 [P]、标准 [S]、报纸 [N]、网页 [EB/OL]。选哪个类型就换哪套格子，字段和标点都不一样
- **著者按国标收敛**：超过三个只留前三个，中文补「等」、外文补「et al」；外文姓在前且全大写、名只留首字母、不加缩写点
- **标点全自动**：题名末尾多余的句号去掉，页码里的破折号 / 波浪号 / 「至」统一成半角短横，无卷无期无页码时不留悬空的冒号
- **生成即入列表**：判重按「去空白 + 小写」的全文比对，同一条不会重复入列
- **重排**：按录入顺序 / 按年份倒序 / 按作者字母，序号跟着重排
- **导出**：复制成 `[1] [2] [3]` 编号列表，或纯文本、Markdown 列表
- 列表免费存 3 条，解锁后 20 条

## 核心设计

### 一条著录 = 一个定序的字符串拼装

八种类型不是八份模板文本，而是八段拼装逻辑 + 一张「字段 → 标签」表。
`TYPE_FIELDS` 决定界面上的格子顺序，`build()` 按类型走不同分支，但共用同一套
著者格式化、年份校验、页码规范化。

好处是「可选字段缺了就自动收敛」这件事只写一次：期刊没卷有期 → `刊名, 2021(5)`；
没有页码 → 结尾不留 `: `。要是每种类型各写一份模板，这些边界迟早会漏。

### 著者：先判断「名在前还是姓在前」

这是最容易做错的一处。用户可能写 `John Smith`，也可能写 `Smith J A`。
判断规则：从尾部数连续的单字母（长度为 1）当缩写名，剩下的就是姓。

- `Smith J A` → 姓 `Smith`，缩写 `J A`
- `John A Smith` → 尾部不是单字母 → 走「名在前」分支，姓 `Smith`
- `van der Waals J` → 姓 `van der Waals`（复姓不会被截断）

中文名一律连写（`张 三` → `张三`），不做繁简或拼音转换。

### 判重按归一化全文

`去空白 + 转小写` 后再比对。只差空格或大小写的两条会被判成同一条，
返回已有下标，页面据此提示「这条已经存过了」。

### 失败返回对象，不抛异常

`{ ok:false, code, message, field }`。页面把 `message` 直接弹 toast，
`field` 用来定位是哪一格填错了。code 给测试和分支用：
`EMPTY` / `TOO_LONG` / `BAD_TYPE` / `BAD_YEAR` / `BAD_VOLUME` / `BAD_URL` / `DUP` / `FULL`。

## 广告位

`core/ads.js` 顶部有一个常量：

```js
var AD_UNIT_ID = '';   // 拿到流量主后填这里
```

**现在是空的，这是有意的**。新小程序没有流量主权限（需累计独立访客 ≥1000），此时填任何 ID
都会触发「广告拉取失败」。所以代码做了降级：拉不到广告 → 视为解锁成功，直接放行。

## 已知限制

- 只覆盖 GB/T 7714-2015 的常见八类，不处理析出文献（`[M]//`）、古籍、档案等冷门类型
- 西文姓名的「名在前/姓在前」靠尾部长度的启发式判断，遇到 `Li Wei` 这种两字姓名
  会按「名在前」处理（姓 `Wei`）；写 `Wei L` 或 `Li, Wei` 之外的写法请自行确认
- 作者分隔符会吃掉逗号，所以 `Smith, John` 这种「姓, 名」写法会被当成两个作者
- 不做 DOI / URL 自动抓取，全部靠手填
- 列表存本地 Storage，换设备不同步
