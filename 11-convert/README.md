# 单位换算

输一个数值、选好两个单位，结果、同类别对照和换算依据一起给。纯本地计算，不联网、不登录。

系列第十一个工具，一天一个。

## 功能

- **六类常用单位**：长度（`mm cm m km in ft`）、质量（`g kg t oz lb`）、面积（`cm² m² km² 亩 ha ft²`）、温度（`°C °F K`）、压力（`Pa kPa MPa bar psi kgf/cm²`）、功率（`W kW MW hp kcal/h`）
- **主结果给大数字**：`12 mm` → `0.4724409 in`，一眼能读，下面跟精确值和反向核对
- **同类别全单位对照**：当前数值在这六个单位里各是多少，一张表看完，不用一个个换
- **附换算依据**：`1 mm = 0.001 m，1 in = 0.0254 m`，用的是定义值不是约等值
- **换目标单位即时重算**：`in → ft` 点一下，同一组数跟着变，不用重新输入
- **温度单独处理**：仿射关系按公式算，`0°C = 32°F`，不会被当成比例算成 0；低于绝对零度直接拦
- **批量换算**：一次多值（免费 1 个，解锁后 8 个），出逐值对照表
- **一条复制**：`12 mm = 0.4724409 in`，多值一行一条，直接贴进表格或邮件

## 核心设计

### 只存系数，不存两两换算表

每个单位只记一个数：`1 个该单位 = 多少个基准单位`。

| 类别 | 基准 | 例 |
|---|---|---|
| 长度 | m | `in = 0.0254` |
| 质量 | kg | `lb = 0.45359237` |
| 面积 | m² | `亩 = 2000/3`，`ha = 10000` |
| 压力 | Pa | `psi = 6894.757293168361` |
| 功率 | W | `hp = 735.49875` |

换算走两级：`值 × 源系数 ÷ 目标系数`。六个单位两两组合是 30 对，存表就是 30 个数还有可能对不上；
存 6 个系数就只有 6 个数，任意一对都能算，而且**天然自洽**。

自洽这件事能当测试用：`a → b → a` 必须精确回到原值。`test.js` 第 5 组对六个类别所有单位对、
每个都跑 5 个量级（0.5 / 1 / 12 / 273.15 / 1234.5678），一共 300 多组。
系数抄错一位、或者某个单位写成「约等于」，这一组立刻挂。

第 3 组再拿法定定义值硬对一遍，防「自洽但错」：`1 in = 25.4 mm`、`1 lb = 0.45359237 kg`、
`1 psi = 6894.757293168361 Pa`、`15 亩 = 1 ha`。

### 温度不能塞进「乘系数」的框架

温度是仿射关系，零点和刻度都不一致，`°F` 不是 `°C` 的某个倍数。
硬套比例换算，`0°C → °F` 会算出 0，正确是 32。

所以温度单独一组函数，统一先转开尔文再转出去：

```
°C → K :  K = C + 273.15
°F → K :  K = (F - 32) × 5/9 + 273.15
K → °C :  C = K - 273.15
K → °F :  F = (K - 273.15) × 9/5 + 32
```

开尔文是绝对温标，顺带成了一道物理闸门：`-300°C` 会算成 `-26.85 K`，数字看着没问题，
物理上不存在。换算前先算开尔文，小于 0 直接返回 `PHYS` 错，提示「低于绝对零度」。
`-273.15°C` 正好 0 K 放行，`-274°C` 就拦。

### 数字格式两套：显示的和精确的

- `fmt()`：7 位有效数字、去尾零，给屏幕和复制用。`1 m → ft` 是 `3.280839895013123`，屏幕上给 `3.28084`
- `exact()`：不截断，给「精确值」和「换算依据」两处用

`|v| ≥ 1e9` 或 `< 1e-6` 才转科学计数。`12 mm → km` 是 `0.000012` 而不是 `1.2000e-5`——
后者在工程语境里没人这么读。

### 输入规则

- 一行一个数，也认空格 / 逗号 / 分号 / 顿号，中英文标点都能分
- 全角减号 `−` 和长破折号 `—` 当负号处理（手机输入法很容易打出这个）
- 重复数值自动去重：同一个数算两遍没意义
- **只有温度能是负数**。长度 `-5mm` 没有物理意义，直接报错比静默算出 `-5` 更安全
- 上限 `1e12`、输入上限 200 字符，超了给码 `LONG` / `BAD`
- 超出免费额度不报错，截断并提示「前 N 个已换算」

失败一律返回 `{ ok:false, code, message }`，不抛异常。`code` 给测试和分支用：
`EMPTY` / `BAD` / `LONG` / `PHYS`。

## 广告位

`core/ads.js` 顶部有一个常量：

```js
var AD_UNIT_ID = '';   // 拿到流量主后填这里
```

**现在是空的，这是有意的**。新小程序没有流量主权限（需累计独立访客 ≥1000），此时填任何 ID
都会触发「广告拉取失败」。所以代码做了降级：拉不到广告 → 视为解锁成功，直接放行。

## 已知限制

- 每类只留了 6 个单位以内（一行 chip 放得下），冷门单位没做：`n mile`、`gr`、`carat`、`mmHg`、`Torr`、`PS` 都没进来
- 只做线性量和温度，没做对数单位（`dB`、`pH`）和复合单位（`N·m`、`kg/m³`）
- 有效数字取 7 位，做高精度核算要拿 `exact()` 的值
- 面积里的「亩」按 `2000/3 m²`（国标），和某些地方口口相传的 `666.67` 差一点点
- 结果不存历史，刷新即清空
